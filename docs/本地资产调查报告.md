## MOD 结构调查

### RustTheWheel (RTW)

- **压缩包内容**: 914 个文件，核心 MOD 目录 `RustTheWheel/`
- **关键文件类型**:
  - `module.ini` - 无 `compatible_with_warband` 字段 (缺失，表明原版 1.011 格式)
  - `troops.txt` - 内容: 588 个 troop 条目 (troopsfile version 1)
  - `factions.txt` - 内容: 25 个 faction 条目 (factionsfile version 1)
  - `item_kinds1.txt` - 内容: 596 个 item 条目 (itemsfile version 2)
  - `map.txt` - 2.4MB 地图数据
  - `mission_templates.txt` - 91KB 任务模板
  - `module.ini` - 无 warband 兼容性标记
  - `music/` - 5 OGG 音乐文件
  - `Resource/` - 11 BRF 编译资源文件 (banners_b.brf, blood.brf, etc.)
  - `SceneObj/` - 30+ .sco 场景对象文件
  - `languages/` - 多语言 CSV 文件 (en, cn, 等)
  - `menus.txt`, `dialog_states.txt`, `conversation.txt`, `scripts.txt`, `quick_strings.txt`, `parties.txt`, `particle_systems.txt`, `game_variables.txt`
  - `menus.txt` - 包含单城镇/战役菜单结构
  - `Changelog.txt` - 2012 年 7 月的更新日志

- **源码状态**: 压缩包内**无** `module_*.py` 源码文件，`module.ini` 为已编译的数据 MOD
- **玩法类型**: 完整单人战役 (有地图、城镇、村庄、任务、队伍管理、对话树)
- **依赖**: 完全依赖原版游戏资源，无额外外部依赖

### Splatterhouse

- **压缩包内容**: 747 个文件，145MB
- **关键文件类型**:
  - `module.ini` - **有** `compatible_with_warband = 1`，`works_with_version_max = 1011`，`display_wp_firearms = 1`，`damage_interrupt_attack_threshold_mp = 1.0`
  - `menus.txt` - 完整单人战役菜单 (menu_start_game_0, menu_start_phase_2, character creation, caravan travel)
  - `mission_templates.txt` - 49 个任务模板 (mst_town_default 等)
  - `triggers.txt` - 24 个触发器
  - `simple_triggers.txt` - 4927 行
  - `dialog_states.txt` - 对话状态
  - `conversation.txt` - 对话内容
  - `troops.txt` - 部队定义
  - `factions.txt` - 阶级定义
  - `item_kinds1.txt` - 物品种类
  - `scene_props.txt`, `scenes.txt` - 场景定义
  - `scripts.txt` - 脚本
  - `variables.txt`, `variable_uses.txt` - 变量系统
  - `sounds/` - 音效文件夹 (Splattermusic*.ogg 等)
  - `Textures/` - DDS 纹理 (Artificer.dds, banners_kingdoms.dds, 等 70+ 个)
  - `languages/` - 多语言 CSV (cns, cnt, de, fr, 等)
  - `tag_uses.txt` - 标签使用说明

- **源码状态**: 压缩包内**无** `module_*.py` 源码文件，`module.ini` 已标记 `compatible_with_warband = 1` (已编译/适配过战版)
- **玩法类型**: **双模式** - 既有完整单人战役结构，也有多任务模板
  - 单人要素: menu_start_game_0 (角色创建), caravan travel, village/town interactions, arena combat, narrative progression
  - 多任务要素: `mst_multiplayer_dm`, `mst_multiplayer_tdm`, `mst_multiplayer_hq`, `mst_multiplayer_cf`, `mst_multiplayer_sg`, `mst_multiplayer_bt`, `mst_multiplayer_duel` (8 种多任务模板)
  - 多播种子: `multiplayer_server_on_agent_spawn_common`, `multiplayer_server_player_joined_common` 在 scripts.txt 中出现
- **证据评级**:
  - 单人战役: **已确认** - 有完整的 menu_start_game_0, character creation, caravan, town interactions
  - 联网多玩: **推断** - 有 mst_multiplayer_* 任务模板和 server 相关 scripts，但未验证实际联网运行
